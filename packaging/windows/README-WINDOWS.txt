HAMSTER MOOD CAM - GUIA SENCILLA PARA WINDOWS
==============================================

ABRIR
-----
1. Abre la carpeta HamsterMoodCam que extrajiste del ZIP.
2. Haz doble clic en HamsterMoodCam.exe.
3. Si Windows pide permiso para usar la camara, pulsa Si o Permitir.
4. Si aparece SmartScreen, pulsa Mas informacion y despues Ejecutar de todas
   formas.

No abras el programa directamente dentro del ZIP. Primero debes hacer clic
derecho sobre el ZIP, elegir Extraer todo y pulsar Extraer.

USAR
----
Mira hacia la camara con buena iluminacion. La camara aparece a la izquierda y
el meme aparece a la derecha.

Para cerrar, haz clic dentro de la ventana y pulsa la tecla Q.

BORRAR COMPLETAMENTE
--------------------
1. Cierra el programa pulsando Q.
2. Haz clic derecho sobre la carpeta HamsterMoodCam.
3. Selecciona Eliminar.
4. Elimina tambien el ZIP original de la carpeta Descargas.

Eso es todo. El programa es portable: no se instala, no inicia solo y no agrega
servicios ni claves al Registro. Tambien puedes abrir UNINSTALL.bat y pulsar S.

SI LA CAMARA NO APARECE
-----------------------
1. Cierra Zoom, Meet, Teams u otro programa que use la camara.
2. Abre Configuracion de Windows.
3. Entra en Privacidad y seguridad, despues Camara.
4. Activa el acceso a la camara para aplicaciones de escritorio.
5. Abre HamsterMoodCam.exe otra vez.

PRIVACIDAD
----------
La camara se procesa localmente y solo en memoria. No se guardan fotos, videos
ni resultados y no se entrena ningun modelo con tu rostro.
