HAMSTER EMOTION DETECTOR - WINDOWS
==================================

ABRIR
-----
1. Extrae TODO el contenido del ZIP.
2. Haz doble clic en HamsterEmotionDetector.exe.
3. Permite el acceso a la camara si Windows lo solicita.
4. Pulsa Q para cerrar.

El programa es portable: no necesita instalador, Python ni Internet.

WINDOWS SMARTSCREEN
------------------
El ejecutable no esta firmado digitalmente. Si Windows muestra una advertencia:
1. Pulsa "Mas informacion".
2. Confirma que descargaste el archivo desde la pagina oficial del proyecto.
3. Pulsa "Ejecutar de todas formas".

BORRAR
------
1. Cierra HamsterEmotionDetector.exe.
2. Elimina esta carpeta completa.
3. Elimina tambien el ZIP descargado si todavia lo conservas.

Como alternativa, abre UNINSTALL.bat y pulsa S.

No se crean servicios, entradas de inicio, claves del Registro ni archivos de
usuario fuera de esta carpeta.

PRIVACIDAD
----------
Los fotogramas se procesan en memoria. No se guardan fotos ni videos y no se
entrena ningun modelo con tu rostro.
